Block **B3** is Phase 3 of [docs/PLAN.md](https://github.com/sebastian-suarez/turning-table/blob/main/docs/PLAN.md#phases). Build order: B3 → B4 → B5 → B6 (the **Order** field on the board); the keys match the phase numbers, and phases 0-2 are done and recorded in the plan. The plan holds the design; this card holds the progress: tick a step only after verifying it, and say how it was verified in a comment. The plan gives no time estimates, so the steps carry none; the Phase 3 spec (`docs/phase-3-spec.md`, not written yet) refines this list.

**Delivers:** scan mode on the bench: the arm stepper as a second controller instance with `ARM <deg>`, and `SCAN <rings> <stops> <pause_ms>` running K ring angles × N platter stops from the serial console.
**Comes after:** Phase 2 (done 2026-10-26). **Comes before:** B4.
**Done when:** a 36-stop scan runs unattended from one command.

## Steps

- [ ] Write the Phase 3 spec (`docs/phase-3-spec.md`), attack it, freeze it.
- [ ] Arm stepper on D6, D7, D8, D10 as a second controller instance in the same 1 ms TC2 tick.
- [ ] Measure the arm motor's gearbox ratio (63.68395:1 or 64:1) and record its constant.
- [ ] `ARM <deg>` through the ~8:1 reduction, with its own calibration.
- [ ] Clock correction for scan pauses: the board's clock runs 0.70 % slow, so calibrate a correction (or a margin) that keeps the pauses in step with RealityScan's interval timer.
- [ ] `SCAN <rings> <stops> <pause_ms>`: K ring angles × N platter stops, a pause matched to the interval timer (or a manual tap), an LED cue.
- [ ] Pushbutton that starts or advances a scan.
- [ ] Settings kept in EEPROM.
- [ ] Command parser and motion math in `turntable-core/`, covered by host `cargo test`.
- [ ] Host rule from the Phase 2 review in the protocol: `ERR LINE` means resend the last unacknowledged command, and so does a reply timeout right after an unsolicited `ERR LINE`.
- [ ] Flash within the Phase 3 budget of 16 KiB (`avr-size -A`; Phase 2 used 8134 B).
- [ ] Exit run: a 36-stop scan unattended from one command, console output pasted in a comment.
